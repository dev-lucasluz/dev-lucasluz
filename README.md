### Série Olist: dados de ponta a ponta
Quatro projetos sobre o mesmo dataset público de e-commerce, cada um construído sobre o anterior:

1. [**olist-etl-java**](https://github.com/dev-lucasluz/olist-etl-java): pipeline em Java que limpa 8 arquivos CSV e carrega tudo em SQLite.
2. [**olist-sql**](https://github.com/dev-lucasluz/olist-sql): modelo estrela e 13 análises de negócio em SQL.
3. [**olist-previsao-atraso**](https://github.com/dev-lucasluz/olist-previsao-atraso): modelo em Python que estima o risco de atraso de cada pedido.
4. [**olist-dashboard**](https://github.com/dev-lucasluz/olist-dashboard): dashboard em Power BI que junta tudo.
